# 🎮 Dev Gamers

**Dev Gamers** é uma aplicação de e-commerce desenvolvida para o segmento de hardware e tecnologia gamer. A plataforma simula uma loja virtual especializada em componentes e periféricos para computadores, oferecendo aos usuários uma experiência de navegação e compra intuitiva.

O projeto foi desenvolvido utilizando React, com foco em componentização, reutilização de código, gerenciamento de estados e integração com serviços externos.

## 🚀 Funcionalidades

- **Catálogo de produtos:** exibição de componentes e equipamentos para PC gamers, como placas de vídeo, processadores, monitores, gabinetes e periféricos.
- **Navegação por categorias:** organização dos produtos para facilitar a localização dos componentes desejados.
- **Carrinho de compras:** possibilidade de adicionar produtos, atualizar quantidades e remover itens.
- **Persistência de dados:** utilização do LocalStorage para manter os produtos adicionados ao carrinho mesmo após atualizar a página.
- **Resumo do pedido:** cálculo automático do valor total dos produtos, considerando suas respectivas quantidades.
- **Finalização de pedidos:** integração com a API para envio das informações do pedido.
- **Integração de pagamentos:** utilização do Stripe para integração com serviços de processamento de pagamentos.
- **Checkout:** fluxo de pagamento integrado para proporcionar uma experiência de compra mais próxima de um e-commerce real.
- **Feedback visual:** notificações para informar o usuário sobre as ações realizadas durante a navegação e o processo de compra.

## 🛠️ Tecnologias utilizadas
As principais tecnologias e bibliotecas utilizadas no desenvolvimento foram:

- **React:** construção da interface através de componentes reutilizáveis.
- **Vite:** ambiente de desenvolvimento e ferramenta de build.
- **JavaScript (ES6+):** implementação das funcionalidades e regras de negócio.
- **Styled Components:** estilização dos componentes utilizando CSS-in-JS.
- **Material UI:** utilização de componentes e recursos visuais.
- **React Router DOM:** gerenciamento da navegação entre páginas.
- **Context API:** compartilhamento e gerenciamento de estados globais, como o carrinho de compras.
- **Axios:** comunicação HTTP com a API.
- **React Hook Form:** gerenciamento de formulários.
- **Yup:** validação de dados.
- **React Toastify:** notificações e feedback visual.
- **Stripe:** integração com serviços de pagamentos online.

## 🧠 Conceitos aplicados
Durante o desenvolvimento do Dev Gamers, foram trabalhados conceitos importantes do desenvolvimento Front-End:

- Componentização e reutilização de componentes.
- Gerenciamento de estados com React Hooks (`useState`, `useEffect` e `useContext`).
- Criação e gerenciamento de Context API.
- Manipulação de arrays com métodos como `map`, `filter` e `reduce`.
- Persistência de informações utilizando LocalStorage.
- Consumo de APIs e requisições assíncronas.
- Gerenciamento de rotas.
- Validação e gerenciamento de formulários.
- Integração com serviços externos de pagamento.
- Organização e separação de responsabilidades.


## 🎯 Objetivo do projeto

O Dev Gamers foi desenvolvido com o objetivo de colocar em prática conhecimentos de desenvolvimento Front-End com React, simulando um cenário real de comércio eletrônico.

Mais do que construir uma interface visual, o projeto busca aplicar conceitos de arquitetura de componentes, gerenciamento de estados, persistência de dados, comunicação com APIs e integração com serviços de pagamento, aproximando o desenvolvimento de uma aplicação de um contexto real de mercado.
